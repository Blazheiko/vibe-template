# Backend scripts

| File                      | Run                                                                        | What it does                                                                                                                                                                                                                                                                                                                                                       |
| ------------------------- | -------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `send-test-email.ts`      | `pnpm --filter backend mail:test <recipient@example.com> [subject]`        | Sends a test email through the configured mail driver (`emailService`) to check SMTP settings. Reads `packages/backend/.env`.                                                                                                                                                                                                                                      |
| `generate-vapid-keys.ts`  | `pnpm --filter backend push:vapid [--write] [--force]`                     | Generates a VAPID key pair for Web Push. Prints it, or with `--write` saves it to `packages/backend/.env`; refuses to replace existing keys without `--force` (that breaks existing subscriptions).                                                                                                                                                                |
| `bench-response-check.ts` | `pnpm --filter backend bench:response`                                     | Benchmarks the response contract check (feat-046): `JSON.stringify`, the previous check, `reject` on a clean response and the whole path of a response with undeclared keys. Prints a table of medians.                                                                                                                                                            |
| `purge-llm-prompts.ts`    | `pnpm --filter backend llm:purge-prompts [--dry-run] [--all] [--days=<n>]` | Empties the stored prompt text of `llm_text_usage` and keeps its SHA-256 and length (feat-065). Without `AI_USAGE_STORE_PROMPTS=true` it removes all text; with it, text older than `AI_USAGE_PROMPT_RETENTION_DAYS`. Idempotent; run it from cron for a retention.                                                                                                |
| `run-job.ts`              | `pnpm --filter backend job:run <name> [--dry-run]`                         | Runs one scheduled job now (feat-222) under the same Redis lease as the scheduled run: while the job runs elsewhere it answers busy with exit code 75; interrupted, 130; a failed run, 1 (through `pnpm` every non-zero code is 1). Does not change the schedule state. Needs Redis. See [Scheduler](https://blazheiko.github.io/vibe-template/backend/scheduler). |

Database scripts (`db:create`, `db:migrate`, `db:seed`, …) live in `src/db/` and are described in [Database](https://blazheiko.github.io/vibe-template/backend/database).
