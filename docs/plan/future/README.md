# Відкладені плани

Плани, які погоджено по суті, але не беруться в роботу, поки не виконається умова, вказана на початку кожного плану. Такі плани не мають запису в `feature_list.json`; id фічі присвоюється, коли план переносять у `docs/plan/` і беруть у роботу.

| План                                                     | Умова старту                                                                                                                     |
| -------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| [Microcaching HTTP-маршрутів](./http-microcache-plan.md) | Microcaching в uWebSockets.js стабільний: знято позначку experimental, кешована відповідь підтримує `writeHeader`/`writeStatus`. |
