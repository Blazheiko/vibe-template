## Why this template

The template grew out of repetitive work: in every new project I had to rebuild authentication, sessions, security, real-time, email, files and an admin panel from scratch. Now it is all in one place, covered by tests and documented, so the next product starts with business logic rather than with the foundation. The documentation is written for developers who see the template for the first time, so it starts with the ["First day"](/en/guide/introduction) path.
