# Scripts

The full list of the monorepo's pnpm scripts. Root scripts run from the repository root (`pnpm <script>`); package scripts run through a filter: `pnpm --filter <package> <script>`. The descriptions are based on the actual `scripts` in each `package.json`.

For day-to-day work it is more convenient to use `make`: [make commands](/en/reference/make) — a single entry point where every target calls one of the scripts below.

## Root

Source: [package.json](https://github.com/Blazheiko/vibe-template/blob/main/package.json).

| Script            | Command                                                                                                          | What it does                                                                                                                                                                                                                                                                                               |
| ----------------- | ---------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `build`           | `pnpm -r build`                                                                                                  | Builds all workspace packages recursively                                                                                                                                                                                                                                                                  |
| `build:shared`    | `pnpm --filter shared build`                                                                                     | Builds only `shared`                                                                                                                                                                                                                                                                                       |
| `dev`             | `pnpm run build:shared && pnpm --filter backend build && pnpm --filter backend --filter frontend --parallel dev` | Builds `shared` and `backend`, then runs the backend and frontend dev servers in parallel                                                                                                                                                                                                                  |
| `dev:manual_test` | `pnpm run build:shared && sh -c '... backend dev & ... api-playground dev & wait'`                               | Builds `shared` and runs the backend and `api-playground` in parallel                                                                                                                                                                                                                                      |
| `dev:backend`     | `pnpm --filter backend dev`                                                                                      | Backend dev server only                                                                                                                                                                                                                                                                                    |
| `dev:frontend`    | `pnpm --filter frontend dev`                                                                                     | Frontend dev server only                                                                                                                                                                                                                                                                                   |
| `docs:dev`        | `pnpm --filter documentation docs:dev`                                                                           | Documentation dev server                                                                                                                                                                                                                                                                                   |
| `docs:build`      | `pnpm --filter documentation docs:build`                                                                         | Builds the documentation site                                                                                                                                                                                                                                                                              |
| `docs:preview`    | `pnpm --filter documentation docs:preview`                                                                       | Previews the built documentation                                                                                                                                                                                                                                                                           |
| `docs:verify`     | `pnpm --filter documentation docs:verify`                                                                        | Verifies the built documentation site                                                                                                                                                                                                                                                                      |
| `services:up`     | `docker compose --env-file packages/backend/.env up -d --wait`                                                   | Starts PostgreSQL (pgvector), Redis, SeaweedFS (S3) and Mailpit from [docker-compose.yml](https://github.com/Blazheiko/vibe-template/blob/main/docker-compose.yml) and waits until all of them are healthy; service names after the script start only those services (`pnpm services:up redis s3 mailpit`) |
| `services:down`   | `docker compose --env-file packages/backend/.env --profile app down`                                             | Stops the local services and the app if it is running; data in volumes is kept                                                                                                                                                                                                                             |
| `app:build`       | `./scripts/docker-build.sh`                                                                                      | Builds the local app image `vibe-template:local` (tag — `APP_IMAGE`) from the `Dockerfile`; arguments are passed to `docker build`                                                                                                                                                                         |
| `app:up`          | `docker compose --env-file packages/backend/.env --profile app up -d --wait`                                     | Starts the services, the one-off `migrate` (`db:create:prod`, `db:migrate`) and the app at `http://localhost:3000` (`APP_PORT`), and waits until healthy. See [Quick start](/en/guide/getting-started#the-whole-app-in-docker-compose)                                                                     |
| `app:down`        | `docker compose ... --profile app rm --stop --force app migrate`                                                 | Stops and removes only the app and migration containers; services and data are kept                                                                                                                                                                                                                        |
| `app:seed`        | `docker compose ... --profile app run --rm --no-deps migrate pnpm db:seed:prod --demo`                           | Reference data and demo accounts (`SEED_*` from `.env`) in the database of the running stack                                                                                                                                                                                                               |
| `app:logs`        | `docker compose ... --profile app logs -f app`                                                                   | App container log                                                                                                                                                                                                                                                                                          |
| `start`           | `pnpm --filter backend start`                                                                                    | Runs the built backend                                                                                                                                                                                                                                                                                     |
| `lint`            | `eslint . && pnpm -r --if-present lint:check`                                                                    | ESLint across the whole repository, then `lint:check` in the packages that have it                                                                                                                                                                                                                         |
| `lint:fix`        | `eslint . --fix`                                                                                                 | ESLint with auto-fix                                                                                                                                                                                                                                                                                       |
| `format`          | `prettier --write "**/*.{ts,tsx,js,mjs,vue,json,md,css}"`                                                        | Formats files with Prettier                                                                                                                                                                                                                                                                                |
| `format:check`    | `prettier --check "**/*.{ts,tsx,js,mjs,vue,json,md,css}"`                                                        | Checks formatting                                                                                                                                                                                                                                                                                          |
| `typecheck`       | `pnpm -r typecheck`                                                                                              | Type checking in all packages                                                                                                                                                                                                                                                                              |
| `test`            | `pnpm -r test`                                                                                                   | Tests of all packages                                                                                                                                                                                                                                                                                      |
| `clean`           | `pnpm -r clean && rm -rf node_modules`                                                                           | Calls `clean` in the packages and removes the root `node_modules`                                                                                                                                                                                                                                          |

## backend

Source: [packages/backend/package.json](https://github.com/Blazheiko/vibe-template/blob/main/packages/backend/package.json).

| Script           | Command                                                                           | What it does                                                                                                                                                                                                                                                                                                             |
| ---------------- | --------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `build`          | `tsc --build`                                                                     | Compiles TypeScript into `dist/`                                                                                                                                                                                                                                                                                         |
| `dev`            | `tsx watch src/index.ts`                                                          | Runs the server with restart on changes                                                                                                                                                                                                                                                                                  |
| `start`          | `node dist/index.js`                                                              | Runs the built server                                                                                                                                                                                                                                                                                                    |
| `clean`          | `rm -rf dist .tsbuildinfo`                                                        | Removes build artifacts                                                                                                                                                                                                                                                                                                  |
| `typecheck`      | `tsc --noEmit`                                                                    | Type checking                                                                                                                                                                                                                                                                                                            |
| `db:create`      | `tsx src/db/create-database.ts`                                                   | Creates the database ([create-database.ts](https://github.com/Blazheiko/vibe-template/blob/main/packages/backend/src/db/create-database.ts))                                                                                                                                                                             |
| `db:create:prod` | `node dist/db/create-database.js`                                                 | Same, from the built code                                                                                                                                                                                                                                                                                                |
| `db:generate`    | `drizzle-kit generate`                                                            | Generates a migration from the schema ([drizzle.config.ts](https://github.com/Blazheiko/vibe-template/blob/main/packages/backend/drizzle.config.ts))                                                                                                                                                                     |
| `db:migrate`     | `drizzle-kit migrate`                                                             | Applies migrations                                                                                                                                                                                                                                                                                                       |
| `db:studio`      | `drizzle-kit studio`                                                              | Opens Drizzle Studio                                                                                                                                                                                                                                                                                                     |
| `db:seed`        | `tsx src/db/seed.ts`                                                              | Initial prompts; with `--demo` — demo accounts ([seed.ts](https://github.com/Blazheiko/vibe-template/blob/main/packages/backend/src/db/seed.ts))                                                                                                                                                                         |
| `db:seed:prod`   | `node dist/db/seed.js`                                                            | Same, from the built code                                                                                                                                                                                                                                                                                                |
| `mail:test`      | `tsx src/scripts/send-test-email.ts`                                              | Sends a test email ([send-test-email.ts](https://github.com/Blazheiko/vibe-template/blob/main/packages/backend/src/scripts/send-test-email.ts))                                                                                                                                                                          |
| `push:vapid`     | `tsx src/scripts/generate-vapid-keys.ts`                                          | Generates a VAPID key pair for Web Push; `--write` writes it to `.env`, `--force` allows replacing existing keys ([generate-vapid-keys.ts](https://github.com/Blazheiko/vibe-template/blob/main/packages/backend/src/scripts/generate-vapid-keys.ts), see [Web Push](/en/backend/web-push-notification#generating-keys)) |
| `test`           | `vitest run`                                                                      | One-off Vitest run                                                                                                                                                                                                                                                                                                       |
| `test:coverage`  | `vitest run --coverage --coverage.reporter=text-summary --coverage.reporter=html` | Run with coverage (`@vitest/coverage-v8`), report in `coverage/`                                                                                                                                                                                                                                                         |
| `test:watch`     | `vitest`                                                                          | Vitest in watch mode                                                                                                                                                                                                                                                                                                     |
| `test:redis`     | `vitest run --config vitest.redis.config.ts`                                      | Integration `*.redis.test.ts` against a real Redis (`REDIS_TEST_URL`); skipped without the variable                                                                                                                                                                                                                      |
| `test:pg`        | `vitest run --config vitest.pg.config.ts`                                         | Integration `*.pg.test.ts` on a temporary database with migrations (`PG_TEST_URL`); skipped without the variable                                                                                                                                                                                                         |

| `preview`       | `vite preview`                                                                    | Preview of the built app                                                                                                             |

| `lint:check`    | `eslint .`                                                                        | ESLint without changes (called by the root `lint`)                                                                                   |
| `format`        | `prettier --write src/`                                                           | Formats `src/`                                                                                                                       |
| `test`          | `vitest run`                                                                      | One-off Vitest run                                                                                                                   |
| `test:coverage` | `vitest run --coverage --coverage.reporter=text-summary --coverage.reporter=html` | Run with coverage (`@vitest/coverage-v8`), report in `coverage/`                                                                     |

## api-playground

Source: [packages/api-playground/package.json](https://github.com/Blazheiko/vibe-template/blob/main/packages/api-playground/package.json).

| Script       | Command                                | What it does                    |
| ------------ | -------------------------------------- | ------------------------------- |
| `dev`        | `vite`                                 | Vite dev server                 |
| `build`      | `run-p type-check "build-only {@}" --` | Typecheck and build in parallel |
| `preview`    | `vite preview`                         | Build preview                   |
| `build-only` | `vite build`                           | Build only                      |
| `type-check` | `vue-tsc --build`                      | Type checking (incremental)     |
| `typecheck`  | `vue-tsc --build --force`              | Full type checking              |
| `lint`       | `eslint . --fix`                       | ESLint with auto-fix            |
| `lint:check` | `eslint .`                             | ESLint without changes          |
| `format`     | `prettier --write src/`                | Formats `src/`                  |

`api-playground` has no `test` script, so `pnpm test` skips it.
