# Project structure

The repository is a pnpm workspace. It includes all packages from `packages/*` and the `documentation` package ([pnpm-workspace.yaml](https://github.com/Blazheiko/vibe-template/blob/main/pnpm-workspace.yaml)):

```yaml
packages:
    - 'packages/*'
    - 'documentation'
```

## Workspace packages

| Package          | Path                      | Purpose                                                                                                                                                                                                                                       |
| ---------------- | ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `backend`        | `packages/backend`        | HTTP/WebSocket server on uWebSockets.js, Drizzle, Redis, S3, email, AI ([package.json](https://github.com/Blazheiko/vibe-template/blob/main/packages/backend/package.json))                                                                   |
| `frontend`       | `packages/frontend`       | Vue 3 + Vite application: PWA, i18n, Pinia, Vitest, Playwright e2e ([package.json](https://github.com/Blazheiko/vibe-template/blob/main/packages/frontend/package.json))                                                                      |
| `shared`         | `packages/shared`         | Shared contracts: `brands`, `schemas`, `responses`, `errors`, `enums`, `utils`, `guards`, `limits`, `patterns` — separate subpath exports ([package.json](https://github.com/Blazheiko/vibe-template/blob/main/packages/shared/package.json)) |
| `api-playground` | `packages/api-playground` | Vue developer tool for manually testing the HTTP/WebSocket API ([package.json](https://github.com/Blazheiko/vibe-template/blob/main/packages/api-playground/package.json))                                                                    |
| `documentation`  | `documentation`           | This documentation site on VitePress ([package.json](https://github.com/Blazheiko/vibe-template/blob/main/documentation/package.json))                                                                                                        |

`frontend`, `backend` and `api-playground` depend on `shared` via `workspace:*`, so `shared` must be built first (`pnpm build:shared`). The dev servers (`vite` and the backend's `tsx watch`) read `shared` straight from `src/` through the `shared-source` export condition ([packages/shared/package.json](https://github.com/Blazheiko/vibe-template/blob/main/packages/shared/package.json)), so a change in `packages/shared/src` reaches HMR and the backend restart without a rebuild. `typecheck`, tests, `vite build`, `start` and Docker have no such condition and read `dist/`.

## Key directories

```
.
├── packages/
│   ├── backend/
│   │   ├── src/
│   │   │   ├── app/        # controllers, middlewares, repositories, routes, routing,
│   │   │   │               # services, start, state, transformers, validate, websocket
│   │   │   ├── config/     # configuration (app, auth, cors, csp, csrf, database, mail, redis…)
│   │   │   ├── database/   # db.ts, redis.ts, schema.ts, relations.ts
│   │   │   ├── db/         # create-database.ts, seed.ts
│   │   │   ├── drizzle/    # migrations/ (generated by drizzle-kit)
│   │   │   ├── openapi/    # unused stubs (OpenAPI is not generated)
│   │   │   ├── scripts/    # utility scripts (send-test-email.ts etc.)
│   │   │   ├── vendor/     # the "core": start/ (server, router), utils/, contracts/, types/
│   │   │   └── index.ts    # entry point
│   │   └── drizzle.config.ts
│   ├── frontend/           # src/, public/, e2e/ (Playwright), vite.sw.config.ts
│   ├── shared/             # src/{brands,enums,errors,guards,responses,schemas,utils}, test/
│   └── api-playground/     # src/{components,composables,router,stores,views}
├── documentation/          # VitePress
├── Dockerfile
├── init.sh                 # install + typecheck + lint + test + build
├── feature_list.json
└── pnpm-workspace.yaml
```

Generated directories (`dist/`, `node_modules/`, Playwright reports, coverage) are not edited by hand ([AGENTS.md](https://github.com/Blazheiko/vibe-template/blob/main/AGENTS.md)).

## Backend import aliases

The backend uses Node.js subpath imports (`#...`). They are declared twice: in `imports` of [packages/backend/package.json](https://github.com/Blazheiko/vibe-template/blob/main/packages/backend/package.json) — for the runtime (they point to `dist/`), and in `compilerOptions.paths` of [packages/backend/tsconfig.json](https://github.com/Blazheiko/vibe-template/blob/main/packages/backend/tsconfig.json) — for TypeScript (they point to `src/`).

| Alias         | Runtime (`package.json`)        | TypeScript (`tsconfig.json`) |
| ------------- | ------------------------------- | ---------------------------- |
| `#app/*`      | `./dist/app/*`                  | `./src/app/*`                |
| `#config/*`   | `./dist/config/*`               | `./src/config/*`             |
| `#vendor/*`   | `./dist/vendor/*`               | `./src/vendor/*`             |
| `#database/*` | `./dist/database/*`             | `./src/database/*`           |
| `#logger`     | `./dist/vendor/utils/logger.js` | `./src/vendor/utils/logger`  |
| `#drizzle/*`  | `./dist/drizzle/*`              | `./src/drizzle/*`            |

::: tip
When adding a new alias, update both places at the same time. Targets in `paths` are set with explicit relative paths (`./src/...`) — `baseUrl` is not used.
:::

## Pinned tool versions

According to [AGENTS.md](https://github.com/Blazheiko/vibe-template/blob/main/AGENTS.md):

- **TypeScript `6.0.3`** — pinned in the root ([package.json](https://github.com/Blazheiko/vibe-template/blob/main/package.json)) and in the packages (`backend`, `frontend`, `shared`, `api-playground`, `documentation`). Versions should be kept aligned.
- **`@typescript-eslint/*`** are kept on a TS 6-compatible line via `pnpm.overrides` in the root `package.json`; update them together with `typescript-eslint`.
- **No `baseUrl`** in the backend `tsconfig`: it is deprecated in TypeScript 6 and will stop working in TypeScript 7.
- **`drizzle-orm` and `drizzle-kit` `1.0.0-rc.5`** — a release candidate; upgrade both together to the same exact version. Relations use Relational Queries v2 (`defineRelations` in [relations.ts](https://github.com/Blazheiko/vibe-template/blob/main/packages/backend/src/database/relations.ts)), migrations use the 1.0 "folder per migration" format ([migrations](https://github.com/Blazheiko/vibe-template/blob/main/packages/backend/src/drizzle/migrations)).
- **Node.js `^24.22.2`**, **pnpm `>=9`** (`packageManager: pnpm@9.15.0`).

For more on the backend, see the [Backend](/en/backend/) section; for commands, see [Scripts](/en/reference/scripts).
