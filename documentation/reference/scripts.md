# Скрипти

Повний перелік pnpm-скриптів монорепозиторію. Кореневі скрипти запускаються з кореня (`pnpm <script>`), скрипти пакетів — через фільтр: `pnpm --filter <package> <script>`. Описи складено за фактичним вмістом `scripts` у кожному `package.json`.

Щоденні операції зручніше запускати через `make`: [Команди make](/reference/make) — єдина точка входу, кожна ціль якої викликає один зі скриптів нижче.

| `dev:backend`        | `pnpm --filter backend dev`                                                                                      | Dev-сервер лише бекенду                                                                                                                                                                                                                                                                                           |

| `docs:verify`        | `pnpm --filter documentation docs:verify`                                                                        | Перевіряє зібраний сайт документації                                                                                                                                                                                                                                                                              |
| `services:up`        | `docker compose --env-file packages/backend/.env up -d --wait`                                                   | Запускає PostgreSQL (pgvector), Redis, SeaweedFS (S3) і Mailpit з [docker-compose.yml](https://github.com/Blazheiko/vibe-template/blob/main/docker-compose.yml) і чекає, доки всі стануть healthy; назви сервісів після скрипта запускають лише їх (`pnpm services:up redis s3 mailpit`)                          |

| `app:up`             | `docker compose --env-file packages/backend/.env --profile app up -d --wait`                                     | Запускає сервіси, одноразовий `migrate` (`db:create:prod`, `db:migrate`) і застосунок на `http://localhost:3000` (`APP_PORT`), чекає healthy. | `start`              | `pnpm --filter backend start`                                                                                    | Запускає зібраний бекенд                                                                                                                                                                                                                                                                                          |

| `clean`              | `pnpm -r clean && rm -rf node_modules`                                                                           | Викликає `clean` у пакетах і видаляє кореневий `node_modules`                                                                                                                                                                                                                                                     |
