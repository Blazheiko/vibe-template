# Скрипти

Повний перелік pnpm-скриптів монорепозиторію. Кореневі скрипти запускаються з кореня (`pnpm <script>`), скрипти пакетів — через фільтр: `pnpm --filter <package> <script>`. Описи складено за фактичним вмістом `scripts` у кожному `package.json`.

Щоденні операції зручніше запускати через `make`: [Команди make](/reference/make) — єдина точка входу, кожна ціль якої викликає один зі скриптів нижче.

## Корінь

Джерело: [package.json](https://github.com/Blazheiko/vibe-template/blob/main/package.json).

| Скрипт            | Команда                                                                                                          | Що робить                                                                                                                                                                                                                                                                                |
| ----------------- | ---------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `build`           | `pnpm -r build`                                                                                                  | Збирає всі пакети workspace рекурсивно                                                                                                                                                                                                                                                   |
| `build:shared`    | `pnpm --filter shared build`                                                                                     | Збирає лише `shared`                                                                                                                                                                                                                                                                     |
| `dev`             | `pnpm run build:shared && pnpm --filter backend build && pnpm --filter backend --filter frontend --parallel dev` | Збирає `shared` і `backend`, потім паралельно запускає dev-сервери бекенду та фронтенду                                                                                                                                                                                                  |
| `dev:manual_test` | `pnpm run build:shared && sh -c '... backend dev & ... api-playground dev & wait'`                               | Збирає `shared` і паралельно запускає бекенд та `api-playground`                                                                                                                                                                                                                         |
| `dev:backend`     | `pnpm --filter backend dev`                                                                                      | Dev-сервер лише бекенду                                                                                                                                                                                                                                                                  |
| `dev:frontend`    | `pnpm --filter frontend dev`                                                                                     | Dev-сервер лише фронтенду                                                                                                                                                                                                                                                                |
| `docs:dev`        | `pnpm --filter documentation docs:dev`                                                                           | Dev-сервер документації                                                                                                                                                                                                                                                                  |
| `docs:build`      | `pnpm --filter documentation docs:build`                                                                         | Збирає сайт документації                                                                                                                                                                                                                                                                 |
| `docs:preview`    | `pnpm --filter documentation docs:preview`                                                                       | Попередній перегляд зібраної документації                                                                                                                                                                                                                                                |
| `docs:verify`     | `pnpm --filter documentation docs:verify`                                                                        | Перевіряє зібраний сайт документації                                                                                                                                                                                                                                                     |
| `services:up`     | `docker compose --env-file packages/backend/.env up -d --wait`                                                   | Запускає PostgreSQL (pgvector), Redis, SeaweedFS (S3) і Mailpit з [docker-compose.yml](https://github.com/Blazheiko/vibe-template/blob/main/docker-compose.yml) і чекає, доки всі стануть healthy; назви сервісів після скрипта запускають лише їх (`pnpm services:up redis s3 mailpit`) |
| `services:down`   | `docker compose --env-file packages/backend/.env --profile app down`                                             | Зупиняє локальні сервіси й застосунок, якщо він запущений; дані у volumes лишаються                                                                                                                                                                                                      |
| `app:build`       | `./scripts/docker-build.sh`                                                                                      | Збирає локальний образ застосунку `vibe-template:local` (тег — `APP_IMAGE`) з `Dockerfile`; аргументи передаються в `docker build`                                                                                                                                                       |
| `app:up`          | `docker compose --env-file packages/backend/.env --profile app up -d --wait`                                     | Запускає сервіси, одноразовий `migrate` (`db:create:prod`, `db:migrate`) і застосунок на `http://localhost:3000` (`APP_PORT`), чекає healthy. Див. [Швидкий старт](/guide/getting-started#увесь-застосунок-у-docker-compose)                                                             |
| `app:down`        | `docker compose ... --profile app rm --stop --force app migrate`                                                 | Зупиняє й видаляє лише контейнери застосунку й міграцій; сервіси й дані лишаються                                                                                                                                                                                                        |
| `app:seed`        | `docker compose ... --profile app run --rm --no-deps migrate pnpm db:seed:prod --demo`                           | Довідкові дані й demo-акаунти (`SEED_*` з `.env`) у базі запущеного стеку                                                                                                                                                                                                                |
| `app:logs`        | `docker compose ... --profile app logs -f app`                                                                   | Лог контейнера застосунку                                                                                                                                                                                                                                                                |
| `start`           | `pnpm --filter backend start`                                                                                    | Запускає зібраний бекенд                                                                                                                                                                                                                                                                 |
| `lint`            | `eslint . && pnpm -r --if-present lint:check`                                                                    | ESLint по всьому репозиторію, потім `lint:check` у пакетах, де він є                                                                                                                                                                                                                     |
| `lint:fix`        | `eslint . --fix`                                                                                                 | ESLint з автовиправленням                                                                                                                                                                                                                                                                |
| `format`          | `prettier --write "**/*.{ts,tsx,js,mjs,vue,json,md,css}"`                                                        | Форматує файли Prettier                                                                                                                                                                                                                                                                  |
| `format:check`    | `prettier --check "**/*.{ts,tsx,js,mjs,vue,json,md,css}"`                                                        | Перевіряє форматування                                                                                                                                                                                                                                                                   |
| `typecheck`       | `pnpm -r typecheck`                                                                                              | Перевірка типів у всіх пакетах                                                                                                                                                                                                                                                           |
| `test`            | `pnpm -r test`                                                                                                   | Тести всіх пакетів                                                                                                                                                                                                                                                                       |
| `clean`           | `pnpm -r clean && rm -rf node_modules`                                                                           | Викликає `clean` у пакетах і видаляє кореневий `node_modules`                                                                                                                                                                                                                            |

[Web Push](/backend/web-push-notification#генерація-ключів)) |
